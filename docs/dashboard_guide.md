# Dashboard Guide

## Report File

`BMW\_Sales\_Dashboard.pbix`

## Confirmed Analytical Content

The measure inventory confirms support for:

* Revenue
* Quantity sold
* Previous-year comparisons
* Quantity growth and variance
* Revenue variance percentage
* Monthly revenue and quantity sparklines

## Report Inventory

* Page names and purposes: Dashboard and All Cars
* KPI cards: Total Revenue, Previous Year Revenue, and Variance Percentage
* Charts and tables: Sales by Country, Quantity Sold by Channel, Revenue by Region
* Slicers and filters: Top 4 Quantity Sold, Top 4 Average Price, All Cars Page Display
* Drill-through pages: None
* Tooltips: Quantity Sold, Average Price
* Bookmarks and navigation: None
* Mobile layout: None

## Usage Instructions

1. Open the report in Power BI Desktop.
2. Refresh the data sources if local paths require updating.
3. Use the report's available filters and navigation controls.
4. Interpret year-over-year measures only when the filter context includes comparable periods.
