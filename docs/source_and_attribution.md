## Source & Attribution

This project was developed as a practical Power BI learning and portfolio project based on a BMW Sales Dashboard tutorial by **@abdelytics** youtube.

The original tutorial provided the project dataset through a Google Drive resource, which was used as the source of the raw data for this analysis. The tutorial also referenced the **SVG Sparkline** resource used to create sparkline visuals within the Power BI dashboard.

### Original Resources

- **Tutorial:** @abdelytics — BMW Sales Dashboard
- **Dataset:** Google Drive resource provided by @abdelytics - https://drive.google.com/drive/folders/1KWjkTnr6PpPSraGD-6eHMhlXu9qi8DJe
- **Sparkline Resource:** SVG Sparkline — used for creating sparkline visuals - https://kerrykolosko.com/visualisations/

> **Attribution:** Credit goes to @abdelytics for the original tutorial, dataset resource, and referenced visualization resources. The Power BI implementation, data preparation, data modeling, DAX measures, dashboard development, analysis, documentation, and business insights presented in this repository were developed as part of my own learning and portfolio work.
